# Wanderlust - Airbnb-like Property Listing Web App

## 🔹 Live Demo
https://wanderlust-project-vn4v.onrender.com

## 🔹 Description
Wanderlust is a full-stack web application that allows users to explore, create, and manage property listings similar to Airbnb.

## 🔹 Features
- User authentication (Login & Signup)
- Create, edit, delete property listings
- Interactive maps using Mapbox
- Image upload using Cloudinary
- Reviews and ratings system
- Responsive UI

## 🔹 Tech Stack
- Frontend: HTML, CSS, Bootstrap, EJS
- Backend: Node.js, Express.js
- Database: MongoDB
- Tools: Git, Render, Cloudinary, Mapbox

## 🔹 Installation
1. Clone the repo
2. Run `npm install`
3. Add environment variables
4. Run `node app.js`
